# 0006: Visual design is pending

- Decided by: owner
- Date: 2026-11-15

## Decision

For now the site uses **browser default styles plus the system font**. Tailwind's preflight reset is left out so markdown keeps the browser's heading, list and link styles. The owner will decide the design later.

## Consequences

- Agents must not introduce colors, fonts, type scales, spacing systems, imagery, animation or other visual styling. Propose instead.
- Layout utilities that a decided feature needs are allowed, for example the links _row_ and the editor's two columns.
